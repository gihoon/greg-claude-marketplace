# Literature Note — 문헌노트 스킬

> "남의 말을 내 말로 바꾸지 못하면, 이해한 것이 아니다." — 니클라스 루만

## 개요

문헌노트는 제텔카스텐의 **소화 과정**입니다. 책, 논문, 영상, 팟캐스트 등에서 얻은 내용을 **반드시 자기 말로 재구성**하여 기록합니다. 원문을 그대로 옮기는 것이 아니라, "이 저자는 이런 주장을 하고 있다"는 형태로 압축합니다.

## 트리거

사용자가 `/do-literature` 또는 `/문헌노트`를 입력했을 때 실행합니다.

**두 가지 모드**를 제공합니다:

| 모드 | 사용법 | 언제 쓰나 |
|------|--------|----------|
| **기본 모드** | `/do-literature 내용` | 하나의 자료를 수동으로 소화할 때 |
| **스캔 모드** | `/do-literature scan` | Inbox에 쌓인 웹 클리핑/자료를 일괄 처리할 때 (Karpathy ingest) |

---

## ═══ 스캔 모드 (Karpathy Ingest) ═══

> "LLM이 소스를 읽고, 요약 페이지를 작성하고, 인덱스를 업데이트하고, 관련 페이지를 수정한다." — Andrej Karpathy

### Scan Step 1: Inbox 스캔

`0 Inbox/`의 모든 `.md` 파일을 읽고 각 노트를 분류합니다:

| 유형 | 판단 기준 | 처리 |
|------|----------|------|
| **출처 있는 자료** | URL, 저자명, 책 제목, 인용문 등이 포함 | → 문헌노트 초안 생성 |
| **개인 생각** | 출처 없이 자기 아이디어만 | → raw 그대로 유지 (스킵) |

분류 결과를 사용자에게 먼저 보여줍니다:

```
📥 Inbox 스캔 결과 (3개 노트)

1. ✅ 20260406 RAG vs 구조화 검색.md → 문헌노트 후보 (URL 포함)
2. ✅ 20260406 카파시 LLM Wiki 번역.md → 문헌노트 후보 (출처 명시)
3. ⏭️ 20260406 내일 할 일 메모.md → 개인 생각 (스킵)

처리할까요?
```

사용자가 확인하면 다음 단계로 진행합니다.

### Scan Step 2: 일괄 문헌노트 생성

각 출처 자료에 대해 **기본 모드 Step 3~5**를 자동 실행합니다:
- 핵심 요약 (자기 말로)
- 주요 개념 정리
- 태그 생성
- 관련 노트 탐색 및 연결
- 영구노트 후보 표시

**중요**: 초안을 생성한 뒤 **각 노트마다 사용자 확인**을 받습니다.
- 확인 → 저장 + 원본을 `3 Archive/`로 이동
- 수정 요청 → 수정 후 재확인
- 스킵 → 다음 노트로

루만 원칙 준수: LLM이 초안을 쓰지만, **사용자가 확인·수정하는 과정에서 "자기 말로 소화"가 일어난다.**

### Scan Step 3: 결과 보고

```
📊 Inbox 일괄 처리 완료

생성: 문헌노트 2개 (d. ..., e. ...)
스킵: 1개
아카이브: 2개 → 3 Archive/
영구노트 후보: 4개 발견

💡 /do-permanent로 영구노트 후보를 발전시키거나, /do-index로 인덱스를 갱신하세요.
```

## 실행 프로세스

### Step 1: 출처 정보 수집

사용자가 출처 정보를 함께 제공했는지 확인합니다.

- **출처가 있으면**: 바로 Step 2로 진행
- **출처가 없으면**: AskUserQuestion으로 질문

```
어떤 자료를 읽으셨나요? 다음 중 해당하는 정보를 알려주세요:

📚 자료 유형: 책 / 논문 / 기사 / 영상 / 팟캐스트 / 기타
📖 제목:
✍️ 저자:
🔗 URL (있으면):
📅 출판년도 (있으면):
```

### Step 2: 핵심 내용 수집

사용자에게 AskUserQuestion으로 질문합니다:

```
이 자료에서 가장 중요하다고 생각하는 내용을 자유롭게 적어주세요.
(인용구, 핵심 논점, 인상 깊었던 부분 등 — 형식은 자유)
```

### Step 3: Claude가 구조화

사용자가 제공한 내용을 바탕으로 Claude가 다음을 수행합니다:

1. **핵심 요약** — 저자의 주장을 1-3문장으로 압축
2. **주요 개념 정리** — 핵심 개념을 번호 매기기로 정리
3. **나의 해석** — 사용자의 관점에서 이 내용이 어떤 의미인지 제안
4. **태그 생성** — 내용에서 핵심 키워드 2-4개 추출
5. **관련 노트 탐색** — 볼트 내 기존 노트를 검색하여 연결

### Step 4: 기존 노트 연결

볼트의 `2 Permanent/`와 `1 Literature/` 폴더를 검색하여:
- 같은 저자의 다른 문헌노트
- 유사한 주제의 영구노트
- 반박하거나 지지하는 관련 노트

를 찾아 `[[위키링크]]` 형태로 연결합니다.

### Step 5: 노트 생성

`1 Literature/` 폴더에 다음 형식으로 저장합니다.

**파일명 규칙**: `[ID]. 내용 중심 제목.md` (ID 뒤에 마침표)
- 예: `a. 미니 마감일로 글쓰기 추진력 만들기.md`
- 예: `a1. 5분 무정지 글쓰기의 원리.md` (a의 하위)
- 예: `b. 복잡계에서 창발이 일어나는 조건.md` (새 주제)

ID 배정 방식은 영구노트와 동일합니다 (알파벳-숫자 교대: a → a1 → a1a → a1a1).
기존 문헌노트를 스캔하여 관련 노트끼리 가까운 ID를 배정합니다.

**노트 서식**:

```markdown
---
type: literature
id: "a"
created: "YYYY-MM-DD HH:mm"
status: 🌿
source:
  type: book | paper | article | video | podcast | other
  title: "제목"
  author: "저자"
  url: "URL"
  year: YYYY
tags:
  - 태그1
  - 태그2
  - 태그3
---
```

## 핵심 원칙

1. **자기 말로 쓰기**: 원문 복사가 아닌, 이해한 내용을 자기 언어로 재구성
2. **출처 명확히**: 항상 출처를 기록하여 나중에 원문을 찾을 수 있도록
3. **하나의 출처 = 하나의 노트**: 출처별로 노트를 분리
4. **영구노트 씨앗 심기**: 독립적 아이디어가 될 수 있는 개념을 표시
5. **비판적 읽기**: 동의/반박 포인트를 명시적으로 기록
